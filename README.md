## What I'm building

### 🏏 [Boundary Bytes](https://github.com/shahparshva72/boundary-bytes)

A cricket analytics platform with interactive statistics, player comparisons, custom report building, games, and multi-league support.

`Next.js` · `React` · `TypeScript` · `Go` · `PostgreSQL` · `Redis`

The backend lives in **[boundary-bytes-go-backend](https://github.com/shahparshva72/boundary-bytes-go-backend)** and uses Go with Chi + pgx for the API/data layer.

### 🎼 [Fletcher Code Review Bot](https://github.com/shahparshva72/fletcher-code-review-bot)

A GitHub App that automatically reviews TypeScript pull requests using structured LLM output, inline review comments, configurable review rules, and provider-agnostic model support.

`TypeScript` · `Probot` · `GitHub Apps` · `Vercel AI SDK` · `Zod` · `Docker` · `Cloud Run`

### 🧭 [Git Blame Narrator](https://github.com/shahparshva72/git-blame-narrator)

Turns repository history into readable engineering narratives instead of making you manually reconstruct context from `git blame` and commit history.

`Effect` · `TypeScript` · `React` · `Drizzle` · `PostgreSQL` · `Redis` · `GitHub OAuth`

### ⚡ [Zap Extension](https://github.com/shahparshva72/zap-extension)

A Chromium extension inspired by Arc Boosts for removing elements, recoloring pages, changing fonts, and overriding text on a per-site basis.

`TypeScript` · `Chrome Extension MV3` · `Vite`
